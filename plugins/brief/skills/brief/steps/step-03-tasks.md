# step 03 tasks

Derive an ordered outcome checklist from the acceptance criteria, following the tasks.md skeleton in references/brief-template.md. One feature, one tasks.md; preserve source identifiers. Give each top-level `##` task a stable `T01`, `T02`, ... prefix so `next` and `ship --tasks` can address it. No fixed phase count or parent-task ceremony unless a real decision remains.

The current SKILL.md owns the workflow policy. User consent is required
before any agent, reviewer or advisor. No automatic validation sessions
for prose; no continuation after a user stop or completed result.
